# Rnetch 0.2.3

Windows x64 按进程代理工具，提供 Rust 核心和 Electron / React 桌面界面。

- TCP 使用 SOCKS5；UDP 可选择 SOCKS5 或 GPUX/1。
- 支持 NetFilter 和 WinDivert 捕获后端，以及 IPv4 / IPv6。
- 支持按进程规则、配置校验、流量统计和运行日志。

## 下载与运行

- `Rnetch-Control-0.2.3-win-x64-both.zip`：桌面便携版。解压后运行 `Rnetch Control.exe`，设置代理参数和进程规则。
- `rnetch-0.2.3-win-x64-both.zip`：CLI 版。编辑 `config.xml`，然后从管理员终端运行 `rnetch.exe config.xml`。按 Enter 或 Ctrl+C 停止。
- `rnetch-source-0.2.3.zip`：当前版本源码，包含 Rust 核心、界面与历史 C++ 存档。
- `WinDivert-2.2.2-source.zip`：随包 WinDivert 的对应源码；运行包内也提供同一份归档。
- `SHA256SUMS.txt`：下载文件的 SHA-256 校验值。

两个运行包均包含 `nfapi.dll`、`nfdriver.sys`、`WinDivert.dll` 和 `WinDivert64.sys`，无需另外下载驱动运行文件。请保持 DLL 与配套 SYS 文件在同一目录。启动捕获驱动需要管理员权限；示例配置中的代理地址需要按实际服务修改。

Rnetch 自有代码采用 MIT 许可证。NetFilter 保留厂商授权与版权说明；WinDivert 采用 LGPLv3 许可选项，附许可证、对应源码及替换说明。第三方组件未按项目 MIT 重新授权。
