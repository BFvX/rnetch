# Rnetch 0.2.4

Windows x64 按进程代理工具。本次更新集中改进 Electron / React 桌面界面的布局、配色和应用图标。

## 更新内容

- 使用白色、浅灰和蓝色配色，增加侧栏导航，重新组织流量、连接、进程规则与运行日志区域。
- 加入以分流路径为主题的专属应用标记，同步到界面、窗口和 Windows 可执行文件图标；提供适配深浅背景的多尺寸 ICO。
- 支持按进程名筛选规则，并改进规则编辑、空列表提示和控件的无障碍标签。
- 增加日志跟随开关，方便暂停自动滚动并查看已有日志。
- 提供使用模拟数据的浏览器设计预览，以及应用图标的深浅背景和小尺寸展示。

TCP 使用 SOCKS5；UDP 可选择 SOCKS5 或 GPUX/1。支持 NetFilter 和 WinDivert 捕获后端，以及 IPv4 / IPv6。

## 下载与运行

- `Rnetch-Control-0.2.4-win-x64-both.zip`：桌面便携版。解压后运行 `Rnetch Control.exe`，设置代理参数和进程规则。
- `rnetch-0.2.4-win-x64-both.zip`：CLI 版。编辑 `config.xml`，然后从管理员终端运行 `rnetch.exe config.xml`。按 Enter 或 Ctrl+C 停止。
- `rnetch-source-0.2.4.zip`：当前版本源码，包含 Rust 核心、界面与历史 C++ 存档。
- `WinDivert-2.2.2-source.zip`：随包 WinDivert 的对应源码；运行包内也提供同一份归档。
- `SHA256SUMS.txt`：下载文件的 SHA-256 校验值。

两个运行包均包含 `nfapi.dll`、`nfdriver.sys`、`WinDivert.dll` 和 `WinDivert64.sys`。请保持 DLL 与配套 SYS 文件在同一目录。启动捕获驱动需要管理员权限；示例配置中的代理地址需要按实际服务修改。
